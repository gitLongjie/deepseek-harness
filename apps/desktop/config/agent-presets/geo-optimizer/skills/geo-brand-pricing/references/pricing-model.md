# 发文成本模型与系数折算

> 本文件所有金额和系数都是**默认假设模板**，用于没有 rate card 时的起算。真实报价必须替换为操作者实际成本表，并在报价假设区块声明。

## 1. 单篇成本 C_post

```
C_post = C_write + C_geo + C_publish + C_revision
```

| 科目 | 档位 | 默认假设（元） | 说明 |
|------|------|--------------|------|
| C_write 写作 | 短文 ≤1000 字 | 400 | 首发撰写 |
| | 长文 1000–2500 字 | 800 | |
| | 深度 ≥2500 字 | 1500 | 含资料调研 |
| C_geo GEO 优化 | 标准 | 写作费 × 0.3 | 9 法：引用来源、统计数据、专家引言、FAQPage schema、answer-first 结构 |
| | 深度 | 写作费 × 0.5 | 含原创数据/测评 |
| C_publish 发布分发 | 自有渠道 | 50/篇 | 官网、公众号、知乎机构号 |
| | 外部媒体 | 按渠道价目 | 媒体投放价从 rate card 渠道表取，无表则让客户指定预算口径 |
| C_revision 复稿维护 | 常规 | 写作费 × 0.15/月 | 30 天内按 AI 引擎引用反馈迭代 |
| | 高竞争 | 写作费 × 0.25/月 | 内容被 AI 引用后需持续保鲜 |

## 2. 可见度系数 k_vis

把「诊断差距」变成价格乘数——起点越低、目标越高，单篇要付的优化强度越大：

```
k_vis = 1 + α × (V_target − V0) / 100
α 默认 0.8：V 差距 40 分 → k_vis = 1.32
```

- V_target < V0（只需保位）时，取 k_vis = 1.0，按防御性维护计价。
- α 反映团队的优化能力溢价：有成功案例的操作者可上调到 1.0–1.2，并在假设区块说明。

## 3. 行业难度系数 k_comp

按品类问题在 AI 回答中的竞争密度分档（探测竞品数量越多、头部垄断越强，档位越高）：

| 档位 | 特征 | k_comp |
|------|------|--------|
| 低 | 长尾 B2B、竞品未布局 | 0.9 |
| 中 | 一般消费品、3 个以上竞品有内容 | 1.1 |
| 高 | 头部垄断（前 2 品牌占据多数引用）| 1.3 |
| 极高 | 医疗、金融等强监管 + 高竞争 | 1.5 |

## 4. 月度报价与速查表

```
月度报价 = N篇 × C_post × k_vis × k_comp + C_monitor
C_monitor 月度 AIVO 监测费：默认 2000 元（探测集复测 + 月报 + 竞品跟踪）
```

## 5. 完整算例

某美妆品牌，V0 = 18（探测 15 条 × 4 引擎，全部可用），目标 V_target = 55，长文档位，外部媒体 2 篇/月走渠道价 300 元：

- C_post = 800 + 800×0.3 + (50 + 300×2/8) + 800×0.15 ≈ 800 + 240 + 125 + 120 = 1285 元
- k_vis = 1 + 0.8 × (55 − 18) / 100 = 1.30
- 消费品中竞争：k_comp = 1.1
- 基础档 N = 8 篇/月：8 × 1285 × 1.30 × 1.1 + 2000 ≈ 16 700 元/月

速查表按 N = 4 / 8 / 12 三档展开（见 quote-table.md）。

## 6. 结算规则选项

- **月结**：默认。按月交付篇数 × 实际档位结算。
- **KPI 对赌**：月末复测 V，未达「阶段目标」（按月均摊 V_target）时按缺口比例退还监测费 + 部分服务费；退款比例必须写进报价假设，不留口头承诺。
- **年度预付**：总价 × 0.85，分季复测校准目标。
