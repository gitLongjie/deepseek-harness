# 去 AI 味

读取目标段落及必要的上下文，确定叙述视角、时代、人物语气和用户希望保留的表达。用户只要求润色时不新增情节、证据、对白含义或人物关系。

定位具体问题而不是依据词汇黑名单改稿：同一段反复解释同一感受；动作之后又总结动作含义；每段都有同样的铺垫与转折；人物说话都像同一个旁白；视角角色知道不可能知道的事；抽象形容词没有动作或感知依据。

逐段选择最小修订：删掉冗余总结，恢复句长变化，把感受落到当前视角能观察的动作或细节，让对白符合人物当时的目的。不能为了口语化随意加入错字、网络梗或方言，也不能把所有修辞都删掉。

交付可直接替换的正文。随后用简短说明标出涉及语义变化的地方；如果某事实不明确，保留原意或单列问题，不编造具体细节。不得承诺绕过 AI 检测或保证“人类创作”判定。

写入前检查改动范围，写入后回读正文；对照原文核对人名、数字、物品、动作先后与对白立场没有被润色改变。
