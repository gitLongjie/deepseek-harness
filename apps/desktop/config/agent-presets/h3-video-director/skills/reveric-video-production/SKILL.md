# Reveric 视频制片流程

本技能把“整部作品可检索、素材有身份、镜头可审查、成片可回溯”作为默认工作方式。它是创作编排层，调用现有视频工具完成执行，不替代模型服务或媒体渲染器。

## 工作区模型

把用户输入整理成五类可复用信息：

1. **作品上下文**：原著或剧本、人物设定、地点、时间线、文风与禁忌。
2. **故事资产**：角色、场景、道具和已有图片/视频。每个资产有稳定 id、外观锚点、参考文件和用途。
3. **分镜计划**：目标、风格、画幅、声音、镜头顺序，以及每镜的机位、动作、开始状态、事件、结束状态和资产引用。
4. **导演约束**：空间布局、行走路线、轴线、人物朝向、左右手和道具归属。
5. **剪辑交付**：片段状态、音视频轨道需求、字幕/配乐要求、成片路径和验收结果。

不要要求用户把整部作品复制到提示词里。能够从当前工作区、已有计划或技能资源读取的信息，直接检索后复用；缺失信息才提出最多三个具体问题。

## 工作台作品工具

先调用 `video_studio_read` 查找已有作品；无作品时通过 `video_studio_save` 创建。读取结果包含 revision，修改须携带该 revision，并从 content_json 去掉 format、version、id、revision、updatedAt。保留无关的 source、blocks、canvas、graph、director 和 edit；实体 id 使用稳定 UUID。冲突后重新读取并比较双方修改，不得只换 revision 强行覆盖。

工作台保存画布卡片、人物关系连线、3D 代理物体位置和相机 viewpoint（x、y、z、fov，相机朝向原点），以及视频、对白、音效、音乐、字幕轨。代理方块预演不是人物模型或动作动画。剪辑片段 start、duration、sourceStart 使用秒，volume 是音量倍数。媒体 source 是受控视频输出目录内的相对路径；不可指定网络地址或目录外文件。字幕片段 name 是字幕正文。

用 `video_studio_export(id, revision)` 导出已保存的剪辑工程；后轨视频覆盖前轨，声音混合，字幕作为 MP4 可选字幕。此操作使用本机 FFmpeg，不生成新素材。没有字幕烧录、复杂转场或动画曲线支持时，不承诺这些效果。真实生成仍使用 video_plan/video_render，作品 UUID 与生成计划 id 不混用。

## 四阶段流程

### 1. 故事到节拍

先确认故事目标、主角、地点/时间、一个主事件、结尾状态和时长。把抽象描述改成可观察动作，例如“她离开房间”要写成“她放下杯子，转身走到门前，推门跨过门槛，沿走廊向右走到电梯”。节拍是动作顺序，不自动等于切镜。

### 2. 节拍到分镜

调用 `video_plan` 前，逐镜写清：`asset_ids`、`prompt`、`start_state`、`event`、`end_state`、`duration_seconds`、`resolution`、`ratio`、`backend` 和 `continuity`。连续动作优先一个 `multi_shot` 任务；只有独立素材、独立路由、明确跳时或必须锁定真实尾帧时才用 `per_segment`。

渲染前逐镜核对：后一镜的 `start_state` 是否复用前一镜的 `end_state`；门窗、通道、机位轴线、人物朝向、左右手、道具归属和动作进度是否一致。`continue` 不得用切镜省略跨门、移动、交接或落位。

### 3. 分镜到素材与视频

缺少角色或场景参考时，先生成并审查素材。角色默认一张四栏设定图（正面全身、侧面全身、背面全身、面部特写），视频首帧只使用所需单栏裁图；布局图和多宫格不能直接作为视频首帧。`multi_shot` 默认只生成并使用第一镜开场图，后续关键帧是审查预览；需要逐镜图像约束时改用 `per_segment`。

用户确认计划和开场图后才调用 `video_render`。连续分段必须传递上一段实际生成的尾帧；没有真实尾帧就停止并报告原因，不能拿目标收尾图冒充实际尾帧。远端生成要先说明成本并取得用户允许，不能静默从本地切到远端。

### 4. 视频到成片

用 `job_output` 收集后台任务结果，检查素材、时长、跳场、重复动作、人物/道具漂移和空间连续性。所有片段成功后调用 `video_assemble`，再用 `present` 交付成片。汇报只列素材清单、关键帧、时长、任务状态、成片路径和已知限制，不复述整份 JSON。

## 与现有工具的对应关系

| Reveric 概念 | 本仓库能力 |
| --- | --- |
| 作品工作区与资产库 | `skill`、文件系统工具、`video_assets`、视频工作台 |
| 画布分镜 | `video_studio_read/save` 保存卡片，`video_plan`、`video_keyframes` 生成分镜 |
| 生成视频 | `video_render`、后台 `jobs` |
| 剪辑台与成片 | `video_studio_export` 多轨导出，`video_assemble` 原计划拼接，`present` 交付 |

本技能不虚构 3D 导演台、非线性时间线或不存在的模型参数；这些能力需要对应插件真实提供后才可使用。

## 交付前检查

- 计划中的每个资产 id 都存在且用途明确。
- 镜头时长之和符合用户要求，连续镜头没有无理由切断。
- 开场图表现的是事件开始前状态；目标收尾图没有被当作真实尾帧。
- 本地/远端后端和费用已明确，失败原因可追踪。
- 成片路径、片段状态和关键限制已展示给用户。
