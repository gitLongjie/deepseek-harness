# 黄金三章

先读题材、目标读者、现有开篇、作品设定和用户指定的节奏。三章结构是诊断工具；用户明确的文学风格、悬疑结构或慢节奏叙事优先，不机械套入爽文模式。

为每章列出开场问题、主角行动、阻力、获得或失去的信息、结尾变化和下一章承接点。第一章让读者看到具体处境与异常；第二章让行动带来代价并改变问题；第三章兑现一次承诺或完成具有后果的选择。

检查故事是否每章都在重复介绍背景，悬念是否只靠作者隐瞒读者本应知道的信息，主角是否一直被动等待，以及章节结尾的问题是否在后续获得回应。

修订时优先移动或压缩说明，保留人物动机与已建立事实。不能为了钩子增加无依据的超能力、突然变坏的配角或与后文冲突的秘密。

交付逐章提纲或完整正文，遵循用户指定的交付形式。附简短的承接检查：第三章结束时角色知道什么、选择了什么、付出了什么、还欠读者哪一个答案。只写提纲时不宣称已经完成三章正文。
