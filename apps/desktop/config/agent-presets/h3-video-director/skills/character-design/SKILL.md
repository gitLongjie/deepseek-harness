# 人设设计

先识别角色在本故事中必须推动的事件，再确定目标、阻碍、可失去的东西和选择代价。为主要角色设计一次能暴露矛盾的行动；不要把职业、身份或性格标签当成完整人设。

角色卡包含：稳定 id、姓名、叙事职责、目标、底线、能力限制、已知信息、关系、语言习惯、视觉描述和当前状态。已有角色先读原卡，再只修改本次需要的字段。

区分长期身份与临时状态。脸型、体态与惯用表达属于身份；伤势、衣着、持有物、所在地点属于场景状态。服装变化不能无意改动年龄、社会身份或面部特征。

为重要关系写出双方各自想得到什么、隐瞒什么，以及哪一次事件会改变关系。使用已有角色 id 引用，不以名字相似推断同一个人。

提供一段对白和一个无对白动作测试角色的可辨识性。用户要求视觉素材时把可观察特征写入 video_plan 资产描述，先查看实际图片接口支持的参考方式；制作模板不是人物设定本身。

交付角色卡与需要作者选择的冲突项。写入用户工作区后回读并给出路径；没有写入时明确标为草稿。
