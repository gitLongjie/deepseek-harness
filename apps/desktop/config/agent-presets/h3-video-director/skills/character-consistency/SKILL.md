# 角色一致性

读取本次正文、相邻章节或镜头、角色卡和用户约束。把已确认事实与草稿设想分开记录；两者矛盾时保留原文并报告冲突，不自动改写已确认设定。

对每个关键动作检查四件事：角色是否知道行动所需的信息，是否有行动能力，动机是否支持这个选择，后果是否改变后续关系。人物成长允许改变行为，但正文必须表现触发原因和代价。

视觉检查用同一角色 id 关联外貌、衣着、参考图及镜头；逐镜对照位置、朝向、伤势、持有物、左右手和动作进度。固定种子与参考图只能提供约束，不能保证生成结果一致。

输出问题表：正文位置或镜头 id、冲突事实、证据来源、影响及最小修复。缺少证据的项目标为待核实，不捏造上文。检查通过也要注明实际覆盖的章节和镜头，不能代表未读取的整部作品。

用户要求修复时保留未受影响正文，写入后回读。生成视频前使用 video_plan 的起止状态表达修复；生成后检查实际视频，不能只检查提示词。
