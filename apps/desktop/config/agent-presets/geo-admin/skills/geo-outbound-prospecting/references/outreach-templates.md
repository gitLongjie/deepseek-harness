# 开发信模板

三版对应 P1–P3。占位符用 `{{}}`，发前逐项替换；`{{品牌}}` 与 `{{产品线}}` 取自第一步核实过的来源。信中不出现未核实数字；需要提及时写「subject to confirmation」。

## 通用规则

- 主题行 ≤60 字符，含品类词与地区线索，不用全大写、不用感叹号、不用「Re:」「Fwd:」伪装回复。
- 正文 ≤180 词，四段：为什么找你 / 我们做什么 / 与你业务的接口 / 一个明确请求。
- 不带附件；要资料等对方回复后再发。首信附件是垃圾判定高发项。
- 英文用英式或美式其一，全篇一致；不使用营销形容词堆叠（world-leading、best-in-class）。
- 落款写客户品牌的真实销售身份，不留空名。

## 跟进节奏

- D+5：一句话补充一个新信息（新增证书、交期确认、同类客户案例），不催回复。
- D+12：换成「要不要我把资料发给你同事」的二选一，给收信人一个体面的转交出口。
- 两封无回应即停，转入季度再触达名单；不在同一季度重复第三封。

## 中文版

用户要求中文时按下述改写：保留四段结构与单一 CTA，标题改为「{{品类}}供应合作——{{公司}}」，身份行与退订行照旧，称呼用「{{公司}} 采购部」，不写「尊敬的领导」。
