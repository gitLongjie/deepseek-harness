# 邮箱核实

## 抓取路径（按优先级）

1. 官网 contact / contact-us / kontakt 页。
2. 德国、奥地利、瑞士公司：Impressum（`/impressum`），法定义务披露，命中率最高；法国看 `/mentions-legales`。
3. `/legal-notice`、`/privacy` 页尾常含 data protection 邮箱，可作备用。
4. 采购专用页：`/procurement`、`/suppliers`、`/vendor-registration`，出现 `purchasing@` / `supplier@` 时优先于通用 `info@`。
5. 官方授权分销商页（如品牌方官网的 distributor locator）——分销商自身的公开邮箱可从该页交叉确认。
6. 行业展商名录（WETEX、ACHEMA、Hannover Messe 等官方目录 PDF 或展商页）。
7. 第三方企业库（Europages、Kompass、Wer-liefert-was）只作线索，必须回官网复现后才升到 A 级。

## 分级判定

| 级别 | 判定条件 | 发信 |
|---|---|---|
| A | 目标公司官网当前页面直接出现该邮箱，抓取成功（HTTP 200），或品牌方官方经销商页列出 | 直接可发 |
| B | 仅出现在第三方目录、企业库、展会 PDF，官网未复现 | 标「待官网确认」，用户同意才发 |
| C | 只有表单、电话、LinkedIn 公司页，无公开邮箱 | 不列入发信名单 |

同一地址在≥2 个独立来源出现只提高可信度，不能替代官网核实：来源可能是同一次抓取的级联转载。

## 记录字段

公司名、国家、城市、画像归属（P1–P4）、邮箱、账号类型（通用/采购/个人）、核实等级、来源 URL、抓取日期、页面当时的职位或联系人（若有）、备注（如表单限制、语言）。

## 排除与降级

- 目录摘录年份超过 3 年且官网查不到 → 判 C，不用。
- 页面返回 409、超时、纯 JS 渲染拿不到文本 → 记「抓取失败」，不得据推测补邮箱。
- `no-reply@`、`jobs@`、`careers@`、`webmaster@` 一律不发。
- 个人邮箱（`姓名@`）只在官网当前页明确列出时使用；德国、法国对个人数据处理更严，优先用角色邮箱。
- 集团总部与目标工厂不一致时，优先目标工厂所在地实体。

## 与检索配合

`web_search` 用于发现候选公司与线索页，`web_fetch` 用于打开具体 URL 取正文。搜索命中目录站时不要停在那里，用它拿到官网域名后再抓官网。工具不可用时如实上报结构化错误，不改用 curl 或自拼 HTTP。
