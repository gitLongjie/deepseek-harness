# 买方画像模板

四类买方覆盖工业品（阀门、执行器、流体控制件、机电配套件）的海外主流采购路径。每类都按同一组字段写，便于横向比较与排序。

字段：**买方类型 / 典型规模 / 采购触发事件 / 决策链角色 / 最在意的三项指标 / 我方对应卖点 / 英文检索关键词**。

## P1 分销商与库存商

- 典型规模：10–200 人，自有仓库，代理 1–3 个欧洲品牌。
- 触发事件：现有品牌断供或涨价、客户问询无人能供的系列、要扩品类、库存周转要求换低价货源。
- 决策链：采购经理 → 总经理（小公司往往老板直决，无技术委员会）。
- 最在意：认证齐全度、交期（对比欧洲 8–12 周）、可贴牌的灵活度、小批量起订。
- 卖点对应：SIL / CE / TS 认证包、衬氟与自力式等补缺系列、白标与定制铭牌、样品政策。
- 检索关键词：`industrial valve distributor <country>`、`valve stockist`、`Armaturen Vertrieb`、`afsluiters leverancier`、`authorized distributor <brand>` 的经销商页。

## P2 工艺 EPC 与机电承包商

- 典型规模：50–1000 人，按项目投标，有 vendor list 制度。
- 触发事件：新厂/扩产/水务项目启动、招标询价、原供应商无法满足交期或认证、业主指定低成本替代。
- 决策链：项目采购 → 专业工程师（否决技术项）→ 项目经理（看进度与罚款条款）。
- 最在意：能否进 vendor list、英文数据表与材质证（EN 10204 3.1）、认证按系列可查、交付节点是否与施工计划对齐。
- 卖点对应：按系列出具的 SIL 证书、紧急切断阀 TS 许可、FAT 与文件包、图纸确认流程。
- 检索关键词：`water treatment EPC contractor`、`desalination EPC`、`cleanroom M&E contractor`、`process pipework contractor`、`skid package fabricator`。

## P3 OEM 设备制造商

- 典型规模：20–500 人，按机型批量采购，重一致性。
- 触发事件：新机型开发、原供应商涨价、客户要求降本、单一来源风险。
- 决策链：研发/设计工程师（选型）→ 采购（价格与账期）→ 质量（批次一致性）。
- 最在意：尺寸与接口可定制、批次一致、样品与打样周期、长期供货承诺。
- 卖点对应：电磁阀岛与角座阀定制、5–10 件打样、小批量柔性产线、图纸化定制。
- 检索关键词：`packaging machine manufacturer`、`filling machine OEM`、`plastic injection molding machine maker`、`burner manufacturer`、`food machinery OEM`。

## P4 终端工厂 MRO

- 典型规模：单厂或集团多厂，走年度框架与备件采购。
- 触发事件：检修季备件、技改、能耗改造（如数据中心冷却优化）。
- 决策链：设备/维修主管 → 采购（框架协议）→ 集团技术标准部门。
- 最在意：停机风险、备件到货速度、与既有品牌的可互换性。
- 处理方式：**不直发开发信**，交给 P1 渠道覆盖；仅在用户明确要求直供时列入。
- 检索关键词：`plant maintenance valve spare parts`，通常只有表单，判 C 级。

## 排序原则

按「可触达 × 单量 × 决策链长度」排序，不要按公司名气排序。EPC 与 OEM 通常响应率高于分销商（有明确在建项目与选型窗口），分销商胜在复购稳定。给结论时写清排序理由与对应证据。

## 排除规则

- 同行阀门/执行器制造商：是竞品，不是客户。
- 体量过大的国家总包（如 L&T、Mott MacDonald）：进不了 vendor list，除非用户点名。
- 纯贸易空壳、无仓储无项目记录：转 P1 前先核员工数与项目案例。
