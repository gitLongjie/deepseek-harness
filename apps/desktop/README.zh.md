# MeowWork 桌面壳

[English](README.md) | 中文

把 harness 打包成可安装产品的 Electron 桌面壳：它启动内置的 `dsh` 运行时，渲染 Web 客户端，并提供浏览器无法拥有的桌面集成。

## 壳提供的能力

- **窗口、托盘与单实例生命周期** —— 常驻单一应用实例、按平台定制的标题栏外观，以及负责恢复与退出的托盘控制。
- **自动更新** —— 通过 `electron-updater` 接入签名的发布通道，并在应用运行期间周期性复查更新。
- **桌面桥接** —— 完成通知、打开会话的 Web 客户端桥、基于 home 补丁层的插件启停，以及来自 OEM 配置的知识库连接管理。
- **OEM 配置** —— 品牌名、品牌标志、问候语、标题与知识库连接事实均可从可部署的 OEM 配置文件和受信环境层解析，一条代码线支撑多个品牌。
- **打包插件闭包** —— 安装器把市场、知识库和业务入口插件包随应用一起发布，裸模块解析基址指向已安装主机。

## 开发

```sh
pnpm run dev:desktop
```

dev 脚本会组装客户端 bundle、准备运行时闭包，并让 Electron 加载仓库源码。打包冒烟与发布构建位于 `scripts/`，通过发布工作流执行。
