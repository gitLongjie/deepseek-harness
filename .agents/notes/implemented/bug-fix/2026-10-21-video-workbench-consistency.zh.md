# Agent Note: 视频工作台分镜与共享素材一致性

Status: implemented

[English](2026-10-21-video-workbench-consistency.md) | 中文

## Problem

视频生成流程记录原始分镜，并跨计划复用角色、场景和道具图片。把多镜头渲染合并为 `all` 后，工作台隐藏了原分镜设置。浏览器独立声明的列表类型也可能与宿主响应不一致。删除某集或某个素材时，后续剧集仍引用的图片也可能被移走。

## Decision

宿主列表持有浏览器仅以类型方式导入的数据声明。每个渲染行按计划顺序携带原始 `shots`；`all` 仍是渲染任务编号。浏览器展示分镜提示词和生成设置，为 `all` 使用完整分镜重新生成请求，并把缺失的视频显示为尚未渲染。多镜头的完整片段同时作为成片，与 `video_assemble` 一致，无需另外生成 final 目录工件。所有计划均不可读时仍显示列表错误。请求计数器阻止旧列表覆盖新刷新，也阻止请求在页面卸载后更新状态。

删除项目或素材时，其他计划的素材或分镜直接引用、同一计划保留的素材或分镜，以及资产库仍引用的文件保留原位。相对与绝对图片路径都经过文件解析器的目录及符号链接检查。回收目录以原子方式分配唯一后缀。删除素材时会备份原计划；移动或计划写入失败时，操作会恢复已经移动的文件并报告失败。无法读取的引用文档会阻止删除，因为其中的引用未知。删除请求 JSON 非法时返回状态 400 的 JSON 错误，损坏的计划文档则分别报告为列表错误。

参考项目为 [Toonflow](https://github.com/HBAI-Ltd/Toonflow-app)，其 README 将剧本、素材和视频片段放在同一创作流程中。[素材工具](https://github.com/HBAI-Ltd/Toonflow-app/blob/master/apps/server/src/utils/assets/index.ts)把素材解析到专属根目录，并在写入时检查版本；[视频设置组件](https://github.com/HBAI-Ltd/Toonflow-app/blob/master/packages/nodes/videoGenerationNode/src/components/generationSettings.vue)显式保留时长、分辨率、画幅和生成模式。这些做法用于指导投影和引用处理；本实现继续使用 Cordis 插件和现有文件生成流程。

## Alternatives considered

**导入完整上游应用。** 上游画布、Vue 组件和运行时不适配现有 Cordis 槽位及 React 客户端。当前生成流程已经负责视频生成和付费操作确认。

**仅保留合成的渲染行。** 这会丢失检查多镜头脚本所需的原分镜编号和设置。

**移走所有带被删计划前缀的文件。** 文件前缀不能表示独占使用：项目资产库和后续计划仍可能引用这些图片。

## Consequences

现有计划 JSON 不变。浏览器类型跟随宿主响应，同时不打包宿主运行时代码。共享图片可以保留到创建它的剧集被删之后；清理不再使用的资产库素材仍是单独的操作。删除未与运行中的生成任务或其他进程协调，因此用户仅在渲染任务结束后删除。

定向测试覆盖损坏计划隔离、旧计划默认模式、分镜保留、多镜头成片映射、共享素材与相对路径图片处理、回滚、非法请求体及过期刷新。真实 Loader 组合运行生成工具，经 Connection 读取其输出，并读取生成的媒体。浏览器保留包内的分镜显示预期文件，因为该显示由项目文件驱动，而非录制的 Session。这些测试未调用外部付费提供方，也未验证打包桌面端播放。
