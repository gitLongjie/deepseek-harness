# Agent Note: Character assets anchor on a full-body reference and document a turnaround sheet

Status: implemented

[English](2026-10-27-video-character-full-body-reference.md) | 中文

## Problem

角色素材原先会生成一张半身定妆照和一张正面/侧面/背面设定表。两张图可能在服装、鞋子和身体比例上不一致；后续镜头使用半身照作为主体参考，同时设定表又作为另一个视觉记录，容易造成冲突。

直接去掉设定表消除了这个冲突，也一并去掉了记录：一张正面图说明不了侧面轮廓、后脑发型，也看不出鞋跟从背后是什么样，服装错误只能等整段视频渲染完才暴露。

## Decision

`video_asset_images` 为每个角色生成一张 3:4 图片作为锚点。提示词要求一个居中的正面站立人物，头顶到鞋底完整可见，并展示手部、服装、鞋子、配饰和身体比例；同时排除半身裁切、三视图、拼贴、文字和水印。这张 `reference` 用于约束关键帧和视频片段。

随后以同一张参考图作为图像请求的主体，画出正面/侧面/背面三视图 `sheet`：三个视角都是对已锚定人物的编辑，因此不会自行换掉外套、发际线或体型。三视图保存到计划和项目素材库、展示给用户，且从不约束关键帧或片段——一张负责锚定，一张负责记录。

只有参考图、没有三视图的角色会被普通调用选中，因此早于三视图能力建立的计划也能补上三视图，而不必重画参考图。`regenerate` 会同时替换参考图与三视图。三视图失败不算素材失败：参考图与此前的三视图保持记录，notice 说明失败原因，缺失的三视图让该角色仍可被重试。本机无法按文件读取的参考图——URL，或已经移动的路径——照常用于生成，只是跳过对话内的图片副本，信封退回为路径。

## Alternatives considered

**保留两张图片，并在后续提示词里说明哪张优先。** 工作台和模型上下文仍然会看到两种人物形象，服装和比例仍可能从设定表中漂移。

**只生成三视图设定表作为锚点。** 宽幅多人物排版不适合作为主体参考，也无法为每个镜头提供一张干净的全身人物图。

**完全不生成设定表。** 参考图会成为唯一记录，设计的侧面与背面只能等到片段生成后才能验证。

**下一次普通调用自动迁移所有旧角色。** 这会在用户没有明确要求时产生图片生成费用，因此只补缺失的三视图，参考图迁移仍绑定到 `regenerate`。

## Consequences

每个新角色需要两次图片请求：先锚点，再由它生成三视图。参考图仍是唯一的主体约束图片，独立渲染的镜头因此沿用一个形象。提示词与结构测试覆盖请求次数、比例、三视图对参考图的条件、补图、失败隔离与清理；实际视觉质量仍需真实 provider 生成和人工检查。

导演智能体在生成素材前自动编写每个角色的规范视觉提示词。它从剧情和用户提供的参考图中提取可观察的身份事实及负面约束，保存到 `asset.prompt`，并按这些事实检查生成结果。用户只需提供剧情和人物信息，不需要手写绘图提示词；已有参考图用于保留稳定身份特征，生成的全身图作为唯一主体参考锚点。
