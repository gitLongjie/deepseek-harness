# 三条完整示例

三条示例覆盖三种模式。看结构，不要照抄内容；时间分段、保持项、音频三轨的位置是固定的。

## 示例一：T2VA · 暴雨后的窄巷

```
【模式】T2VA · 6s · 9:16 · 环境声
【核心创意】暴雨初歇的城中村窄巷，一个送外卖的年轻人把纸箱顶在头上蹚水跑向巷口；写实纪录片质感。
【画面过程】
0.0–1.5s：中景，年轻人站在巷口屋檐下，雨水沿屋檐连成线落下；他低头看一眼手机，把外套帽子扣上。
1.5–4.0s：他把空纸箱举过头顶，踏进积水，水花向两侧溅开；镜头低机位后退跟拍，背景的塑料招牌在风里晃。
4.0–6.0s：他在路灯下停住，纸箱塌了一角，水珠从箱沿滴落；镜头停住，他回头看向巷子深处。
【镜头】中景转中全景，低机位，后退跟拍（track back），匀速
【光线】路灯暖黄顶光＋雨后阴天冷调环境光，高对比，湿地面有反光
【保持项】纸箱始终是同一只，塌角只出现在最后一段；帽子全程扣着；巷宽与招牌位置不变
【音频】环境声：雨滴打在铁皮棚上的密响、积水被踩开的哗声、远处电动车驶过；配乐：无；对白：无
【负向】无字幕、无水印
```

要点：动作只有一件事（跑），但拆成「准备—移动—停住」三拍；环境在每一拍都回应了动作。

## 示例二：I2VA 首尾帧 · 晨光咖啡

```
【模式】I2VA（首尾帧）· 6s · 16:9 · 环境声
【参考素材】@图片1 = 首帧（桌面、咖啡杯已给定）；@图片2 = 尾帧（杯子离开桌面、杯底露出环印）
【核心创意】晨光里一只手把咖啡杯端走，桌面留下一圈水印；只写从首帧到尾帧之间的变化。
【画面过程】
0.0–2.0s：保持首帧构图；一只手从右侧入画，指尖先碰到杯柄，杯身轻微晃动。
2.0–4.5s：手把杯子端离桌面，杯底与木桌分离时带起一丝水汽；桌面露出浅褐色环印，晨光在环印边缘拉出高光。
4.5–6.0s：手把杯子移出画外右上方，镜头不动，画面停在尾帧构图。
【镜头】固定机位，中近景，平视
【光线】左侧窗光，暖色温，阴影柔和；木桌纹理与杯壁水珠保持清晰；全程光不变
【保持项】桌面木纹、杯身 logo、环印位置与尾帧一致；全程不出现第二只手；首帧构图在 0–2 秒内不变
【音频】环境声：窗外鸟叫、瓷杯离开桌面时的一声轻响、衣袖摩擦；配乐：无；对白：无
```

要点：没有重述图片里已有的桌面和杯子，只写了两秒内的变化；尾段主动落到尾帧，而不是另外设计一个结尾。

## 示例三：Ref2VA · 元宵石桥

```
【模式】Ref2VA · 8s · 9:16 · 环境声＋旁白
【参考素材】
@图片1 = 人物参考：锁定脸型、发髻、月白汉服与披帛
@图片2 = 场景参考：锁定石桥结构、灯笼位置、河道走向
@视频1 = 运镜参考：低机位侧向跟拍，匀速偏慢
@音频1 = 音色参考：中年女声，语速偏慢
【核心创意】元宵夜，提灯女子走过石桥，在桥心停下回望；古装写实，暖灯火与冷夜色对撞。
【画面过程】
0.0–2.5s：低机位侧跟，女子提一盏兔子灯从桥头入画，裙摆扫过石阶，灯光在她脸上晃。
2.5–5.5s：她走到桥心停下，把灯换到左手，右手扶住石栏；河面倒影被风揉碎，远处有人放河灯。
5.5–8.0s：她回头看向镜头方向，灯影在瞳孔里缩成一个亮点；镜头停住，背景人声压低。
【镜头】中景，低机位，侧向跟拍转固定
【光线】灯笼暖光作主光，月光冷调补环境，高对比，石栏有潮湿反光
【保持项】脸与发髻不变；汉服月白底色不变；兔子灯全程完整、不熄灭；桥心石栏位置不变
【音频】环境声：河水、远处人声与爆竹余响、灯纸被风吹动的窸窣；配乐：古筝单音，四拍一落；旁白：「灯亮着，人就还在。」（9 字，约 2.5 秒，落在 5.5–8.0s）
```

要点：四份素材各写一句职责；旁白字数按 3.5 字/秒估并标注落点；保持项直接指向参考图里会被模型改动的东西（灯的完整度、汉服颜色）。

## 反例

以下写法不要交给模型：

- 「一个女孩在古镇很唯美地走着，4K，杰作，最佳质量。」——没有动作起止、没有时间、没有光、只有空泛质量词。
- 「参考图片1、视频1，做一个类似的视频。」——素材职责未分配。
- 「她先走过桥，再转身，再招手，然后离开，镜头环绕。」——8 秒内四拍动作加环绕运镜，模型只会挑一个执行。
