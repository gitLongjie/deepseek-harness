# 提示词模板

三种模式共用同一套骨架，差别只在篇幅分配。模板里的方括号必须替换成具体内容，不要原样保留。

## 通用骨架

```
【模式】{T2VA|I2VA|Ref2VA} · {时长}s · {画幅} · {有无音频}
【参考素材】{有则逐份写职责，无则删掉本行}
【核心创意】{一句话：谁，在什么处境下，完成了什么变化}；风格：{锚点}
【画面过程】
0.0–{t1}s：{起始状态} → {动作一}；{环境回应}；{镜头或光线}
{t1}–{t2}s：{动作二}；{环境回应}；{镜头或光线}
{t2}–{总时长}s：{结束状态}；{环境回应}；{镜头落点}
【镜头】{景别}，{机位角度}，{单一运镜}
【光线】{光源与方向}，{色温}，{对比}，{材质细节}
【保持项】{逐条，不可只写“保持一致”}
【音频】环境声：{…}；配乐：{…}；对白：「{…}」（{n} 字，约 {x} 秒）
【负向】{可选，仅必要项}
【假设】{我替用户补的默认值；无则删掉}
```

## T2VA 文生视频

提示词要包揽一切。第一段先建立空间，第二段给动作，最后一段给落点。

```
【模式】T2VA · 6s · 9:16 · 环境声
【核心创意】{场景一句话}；风格：写实电影感
【画面过程】
0.0–?s：{空镜建立空间：地点、天气、光、背景在动的东西}
?s–?s：{主体入画或开始动作}
?s–6s：{动作完成，镜头与画面停住}
【镜头】{中景或中全景}，{平视或低机位}，{固定或单一运镜}
【光线】{主光方向}＋{环境光}，{色温}，{对比}，{地面或材质的反光}
【保持项】{主体外观}；{关键道具状态}；{构图与轴线}
【音频】环境声：{两层以上：近处+远处}；配乐：无；对白：无
```

## I2VA 图生视频 / 首尾帧

图片已经给出主体、布局和开场构图。提示词只写三件事：动作、变化、保持项。

```
【模式】I2VA（{首帧|首尾帧}）· {时长}s · {画幅} · {有无音频}
【参考素材】@图片1 = 首帧；@图片2 = 尾帧（无尾帧则删）
【核心创意】从首帧到尾帧之间发生了什么变化
【画面过程】
0.0–?s：{在首帧构图上开始变化的第一个动作}
?s–?s：{主变化；环境如何回应}
?s–{总时长}s：{落到尾帧状态；镜头是否移动}
【镜头】{固定优先}，{景别}，{机位}
【光线】{光是否变化；不变就写“光不变”}
【保持项】{与首帧一致的外观、道具位置、桌面/背景纹理、尾帧构图}
【音频】环境声：{…}
```

首尾帧的关键是让尾段自然落到尾帧构图，不要额外加运镜去“演”一个结尾。首帧模式则要写清动作结束时的画面停在哪。

## Ref2VA 参考素材

先写素材职责表，再写创意。素材职责不能写成「参考全部素材」。

| 编号 | 职责 | 必须保留 |
|---|---|---|
| `@图片1` | 人物参考：脸型、发型、服装 | 妆容与配饰 |
| `@图片2` | 场景参考：建筑布局、灯笼位置、河道走向 | 空间结构 |
| `@视频1` | 运镜参考：低机位侧向跟拍、速度慢 | 运动轨迹与节奏 |
| `@音频1` | 音色参考：中年女声、语速偏慢 | 音色与语速 |

编号按上传顺序；没有对应职责的素材不要硬编用途。风格参考只锁画风与质感，不锁内容。

## 时间线写法

- 每段 1.5–3 秒；少于 1 秒的动作模型来不及响应，多于 3 秒会显得拖。
- 首段负责建立空间，末段负责给落点：停在动作完成、回头、或画面静止。
- 同一段里不要既推镜又换主体；两者只能选一个。
- 秒数相加必须等于总时长，否则模型会自己压缩最后一段。
