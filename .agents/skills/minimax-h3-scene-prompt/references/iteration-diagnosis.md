# 症状 → 变量 迭代诊断表

生成结果不对时，先对症状查表，只改「只改这个变量」列里的那一项再复跑。一次改两个以上，就无法判断哪句描述起了作用。

| 症状 | 最可能原因 | 只改这个变量 |
|---|---|---|
| 动作没发生或很弱 | 动作写成形容词，或一条里塞了多个动作 | 换成一个可观测动作，写明起始与结束状态 |
| 动作瞬移、顺序乱 | 没有时间分段 | 改写成 `0–Xs：…` 分段，秒数相加等于总时长 |
| 脸崩、身份漂移 | 素材职责不清，或文字外观与参考图冲突 | 指定人物参考；删掉与图冲突的外观重述 |
| 镜头不动或乱晃 | 运镜术语模糊，或叠加了多个运镜 | 只留一个运镜；需要复杂运动时用 `truck left + pan right` |
| 口型对不齐 | 台词相对时长的字数过多 | 按每秒 3–4 个汉字压到 `时长 × 3.5` 字以内 |
| 画面像手机随手拍 | 光线描述空泛 | 补光源方向、色温、对比，以及一处材质反光 |
| 背景漂移、建筑变形 | 运镜幅度过大，或环境未被锁定 | 减小运镜，或增加构图与轴线保持项 |
| 没有声音 | 未写音频三轨 | 补 `overall_soundscape`；配乐与台词分开写 |
| 画面太满、杂乱 | 背景次要运动过多 | 砍到只剩一个环境回应动作 |
| 颜色跳变、前后不一致 | 未固定色调 | 在光线段写死色温，并在保持项里重复一次 |
| 主体出画或被切 | 景别与动作幅度不匹配 | 换景别，或缩小动作幅度 |
| 风格跑成动画或游戏 CG | 缺风格锚点 | 加一句写实锚点：实拍、真实材质、自然光 |
| 产品 logo 或纹理变形 | 没有物体参考 | 加物体参考，并单列「必须保留的 logo 与纹理」 |
| 节奏拖成慢动作 | 没写节奏 | 写明「正常速度」或「停顿在第 X 秒」 |

## 优先级

动作不对时先修动作，不要加风格词。风格词只能改变质感，改不了事件。

## 复跑记录

每次复跑记一行：改动的那一句、改前、改后、结果是否改善。连续两次同一变量无效，说明原因判断错了，回到时间线检查动作顺序。
