# 交付前自检清单

交付提示词前逐条过一遍。任何一条不通过，先补内容，不要用风格词掩盖。

1. **模式写对**：T2VA 包揽一切；I2VA 只写变化；Ref2VA 每份素材都有具体职责，且编号与上传顺序一致。
2. **只有一个主事件**：动词可观测，起始与结束状态都写出来了。
3. **时间分段成立**：秒数相加等于总时长，顺序就是发生顺序。
4. **环境有回应**：至少一段写了主体动作对环境的影响（水花、灰尘、灯影、布料）。
5. **运镜唯一**：只有一个主运镜；组合运动用了标准术语而非「环绕」。
6. **景别与动作匹配**：按这个景别，主体不会出画或被切。
7. **光线可见**：有光源方向；色温、对比、材质细节至少各一项。
8. **风格锚定**：一句话说明写实／广告／动画／纪录片；没有「4K、杰作、最佳质量」这类空词。
9. **保持项完整**：覆盖身份、服装、道具状态、构图与轴线；每条都说明「保持一致于什么」。
10. **音频分轨**：环境声、配乐、对白分开写；台词字数与时长匹配；环境声里不重复台词内容。
11. **不重述可见内容**：I2VA 没有重复图片里已经有的主体与构图。
12. **假设显式**：所有「我替用户定的」默认值都列在假设区块；负向只保留必要项。

## 常见坑

- 用形容词代替动作（「优雅地」不是动作）。
- 一条提示词里塞两个运镜，模型通常只执行第一个。
- 把「环绕运镜」当术语；应写 `truck left + pan right` 并给出速度。
- 台词写成一段独白，口型必然对不上。
- 保持项只写「保持一致」，没说一致于哪一帧或哪张参考图。
- 素材职责写「参考全部素材」，等于没有分配职责。
- 环境声里复述对白或歌词，会让模型把两段声音叠在一起。
