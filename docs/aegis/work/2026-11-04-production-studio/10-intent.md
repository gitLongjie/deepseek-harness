# 制片工作台集成设计

用户要求把剧本编辑、无限画布、3D 导演台、多轨剪辑、关系图谱、故事创作技能和智能体操作集成进当前工作台。验收对象是可以编辑、保存、重开和导出作品的产品，不是导航入口或说明卡片。

## 已确认的集成路线

推荐在 React/Cordis 中独立实现等效能力，保留现有生成服务和桌面架构。直接移植需要适配 Flutter/native 组件并落实上游授权义务；商业授权集成需要先明确已取得的授权范围。用户已明确选择「原生实现同等功能」，据此实施；没有改变产品许可证或联系作者。

## 原生路线的实施设计

1. 作品存储拥有章节、剧本场次、角色卡、场景、资产引用、图谱、画布、导演工程与剪辑工程。所有实体使用稳定 id；保存携带 revision，旧 revision 拒绝覆盖并保留用户草稿。文件路径从受控资产 id 解析；浏览器不能提交任意宿主路径。新增作品数据须有版本、大小限制、原子写入、恢复策略和类型变更记录，不重写已有生成计划。
2. 剧本编辑器支持原著对照、场次/动作/角色/对白/转场元素、增删排序、撤销重做和导出。已有视频计划通过明确转换导入，不能把未填写的原著或对白伪造出来。
3. 无限画布使用适配 React 的成熟画布库；节点可拖动，视图可平移缩放，素材/镜头引用以连线保存。媒体文件仍由现有认证文件路由读取。修改引用影响下一次生成，不能追溯修改旧成片。
4. 3D 导演台使用浏览器 3D 引擎，支持角色与道具占位、移动旋转、相机视图、焦距、运动关键帧、切镜和构图抽帧。占位预演与最终视频分别标识；预演图由用户或智能体显式绑定为生成参考。引擎、模型资产和许可证需独立检查。
5. 剪辑工程包含主视频、叠加、对白、音效、音乐、字幕轨；支持拖入、移动、修剪、分割、静音和音量。Host 将已校验的工程转换为 FFmpeg 参数，通过受控子进程和后台 jobs 渲染，支持取消和错误报告。用实际输出的时长、帧和音轨验证结果，现有 concat 工具不视为多轨渲染器。
6. 关系图谱保存人物/势力/地点等实体之间的带类型关系，以及生效章节和证据来源；编辑连线可回读，节点标签列表不算图谱。叙事关系与镜头素材引用分开保存。
7. 智能体和 GUI 调用同一个作品服务；读、写、检索、预演、生成、导出具有明确输入和结构化结果。模型可见读写通过现有工具日志记录。探索与审查角色默认只读，写作/制片在已授权范围内写入；不新增一套独立 agent loop。
8. 技能按需加载，作品事实不重复塞进所有系统提示。独立技能覆盖人设、角色连续性、黄金三章、文字润色；扩展世界观、章节规划/节奏、长篇连续性、剧本改编和制片指导时也要绑定实际工具及资源。

## 完成标准

每项功能必须完成 UI、持久化、智能体操作和错误路径验证。端到端样例从新建作品开始，写两场剧本，建立人物关系，布置画布与 3D 机位，生成或导入片段，剪辑字幕和音频，导出可播放文件，再重开工程确认数据一致。使用固定本地媒体和模拟外部生成服务提供无密钥覆盖；真实服务测试单独报告。构建成功和标签页可点击不足以证明这些功能完成。
